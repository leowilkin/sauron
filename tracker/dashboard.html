Estimated Effort

Estimate

Your time before each prompt is built from what the prompt shows. Reading: the reply's read time, scaled by how much the prompt engaged with it (at least 30%). Thinking: (problem difficulty + your own reasoning) × the first slider. Writing: measured typing, or your typing pace. Never more than the time that passed, and nothing after Claude Code logged you away. Learning prompts (questions, asking about the agent's work, code with explanation, reviewing it) then count fully; other prompts count in proportion to your own reasoning. Agent time never counts.

Your Labels

Labelling happens next to each prompt in Prompts, where the comparison with the model is shown too. Labels are a local calibration tool and are never published. Agreeing with your own labels tunes the model to your judgement; it doesn't show the estimate measures productive struggle. That needs outside evidence, like observed behaviour or a reviewer's labels.
